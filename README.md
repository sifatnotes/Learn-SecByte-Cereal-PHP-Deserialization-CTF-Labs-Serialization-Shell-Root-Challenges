# Learn SecByte Cereal & PHP Deserialization CTF Labs

A focused collection of **hands-on cybersecurity labs and CTF challenges** covering PHP serialization and deserialization, payload concepts, shell access, Linux enumeration, cron and symlink security, and privilege escalation toward root.

These labs are useful for **cybersecurity students, CTF players, pentesters, SOC analysts, and security learners** studying web application and Linux security in authorized environments.

## Introduction

This repository organizes Learn SecByte challenges around **PHP deserialization, serialization-based vulnerabilities, Linux privilege escalation, shell enumeration, cron security, LinPEAS, and pspy**.

The collection is intended as a learning index. It does not provide leaked flags, credentials, or unauthorized access instructions.
